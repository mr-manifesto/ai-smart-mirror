Smart Mirror Features

01

Face Recognition

Uses the camera feed to detect faces, compare them with trained recognition data, and identify known students or lecturers with minimal manual input.

02

User Dashboard

Shows the recognized person's ID, name, academic information, department details, and attendance in a structured panel that is easy to read during live use.

03

Live Weather

Connects with weather API data to display the current condition and temperature, helping the mirror feel useful beyond recognition alone.

04

Real-Time Clock

Keeps the current time and date visible in the header, so the interface works like a practical smart mirror dashboard throughout the day.

05

Motivational Quotes

Fetches short motivational messages and places them beside the user details, giving the display a more personal and engaging experience.

06

Smart UI

Organizes camera output, user identity, weather, time, and quotes into a clean responsive layout designed for repeated daily interaction.

About

About This Project

AI Smart Mirror is an intelligent system that uses face recognition to identify users and display personalized information such as academic details, weather updates, time, and motivational quotes.

This project combines Artificial Intelligence, Web Development, and IoT concepts to create a smart interactive mirror experience for real-world daily use.
